4. HOW TO VERIFY TECHNICAL SECURITY & POWERSHELL BENCHMARKS (SECTION 2)
====================================================================================================

You can run these PowerShell commands to instantly verify technical quality benchmarks:

1. TEST UNAUTHORIZED ACCESS CONTROL (Blocks missing tokens - HTTP 401/403):
   Invoke-RestMethod -Uri "http://localhost:3000/api/branches" -Method Get
   (Expected Output: Returns error "No token provided", proving route protection).

2. TEST AUTHORIZED JWT ACCESS:
   $login = Invoke-RestMethod -Uri "http://localhost:3000/api/auth/login" -Method Post -ContentType "application/json" -Body '{"email":"admin@bakewise.com","password":"password123"}'
   Invoke-RestMethod -Uri "http://localhost:3000/api/branches" -Method Get -Headers @{Authorization="Bearer $($login.token)"}
   (Expected Output: Returns branch list successfully).

3. TEST BRUTE-FORCE RATE LIMITING (HTTP 429 Protection):
   1..15 | ForEach-Object { Invoke-WebRequest -Uri "http://localhost:3000/api/auth/login" -Method Post -ErrorAction SilentlyContinue | Select-Object StatusCode }
   (Expected Output: Returns 429 Too Many Requests after 10 requests).

4. TEST SERVER UPTIME & SYSTEM HEALTH:
   Invoke-RestMethod -Uri "http://localhost:3000/api/status"
   (Expected Output: Displays online status, database connection type, and server uptime).
