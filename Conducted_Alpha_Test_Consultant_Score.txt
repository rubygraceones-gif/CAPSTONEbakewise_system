Consultant Findings & Technical Remarks:

  - The AI Demand Forecasting microservice (Random Forest Regression) accurately projects required 
    production batches based on historical sales patterns, day of the week, and holiday trends.
  - Automatic shelf-life tracking correctly categorizes products into Fresh, Warning, Critical, and 
    Expired states based on production date and predefined freshness rules.
  - The rule-based Product Repurposing engine effectively generates viable recipes (e.g., Garlic Croutons,

CRITERION 2: PERFORMANCE EFFICIENCY (Weight: 15% | Mean Score: 4.80 / 5.00)
----------------------------------------------------------------------------------------------------
Evaluates system performance relative to the amount of resources used under specified conditions.

Sub-Criteria Evaluated:
  2.1 Response Time Behavior (API endpoint latency < 120ms average) - 4.80/5.00
  2.2 Resource Utilization (Optimized CPU/RAM utilization during AI model execution) - 4.77/5.00
  2.3 Capacity & Throughput (Handles concurrent POS sales logging and bulk updates) - 4.83/5.00

Consultant Findings & Technical Remarks:
  - REST API routes demonstrate high responsiveness with average response times under 100ms.
  - Server-side caching using `apicache` effectively minimizes redundant database queries for static 
    product catalogues and branch configuration queries.
  - Client-side pagination (10 items/page across tables) keeps DOM rendering fast and smooth.

----------------------------------------------------------------------------------------------------
CRITERION 3: SECURITY & ACCESS CONTROL (Weight: 15% | Mean Score: 4.93 / 5.00)
----------------------------------------------------------------------------------------------------
Evaluates the degree to which information and data are protected from unauthorized access or breaches.

Sub-Criteria Evaluated:
  3.1 Authentication & Token Security (JWT token authentication & bcryptjs hashing) - 5.00/5.00
  3.2 Authorization & RBAC (Strict role privileges for Admin, Manager, Sales, Baking) - 4.90/5.00
  3.3 Threat Mitigation & Protection (Helmet HTTP headers, Rate Limiting, XSS sanitization) - 4.90/5.00

Consultant Findings & Technical Remarks:
  - Passwords are securely hashed using `bcryptjs` with standard salt rounds.
  - Middleware `authenticateToken` enforces valid JWT bearer headers across all restricted API endpoints, 
    returning HTTP 401/403 upon missing or invalid tokens.
  - Brute-force protection is enforced via `express-rate-limit` (10 requests/15 mins on login route, 
    returning HTTP 429 status code when exceeded).
  - Cross-Site Scripting (XSS) prevention is guaranteed using `xss-clean` middleware and Helmet CSP headers.
